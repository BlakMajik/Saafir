# SAAFIR — Marcus Saafir Portfolio

Visual brand and editorial portfolio website for **Marcus Saafir** (creatively known as **SAAFIR**).

> *"North Carolina raised. Los Angeles based. Marcus Saafir works across fashion, film, photography, and music."*

## Disciplines & Practice
- **Fashion & Garment Design**: Cut and sew, garment construction, clothing design.
- **Film & Photography**: Camera operation, drone operation, videography, photography, video editing.
- **Music**: Songwriting.
- **LIA**: Independent apparel brand by Marcus Saafir ([@staylia.la](https://www.instagram.com/staylia.la/)).

## Project Structure
```text
saafir/
├── index.html              # Semantic HTML5 homepage
├── assets/
│   ├── favicon.svg         # Monogram SVG icon
│   ├── css/
│   │   └── style.css       # Design system & responsive layout styling
│   ├── js/
│   │   └── main.js         # Interactive navigation, clock, modal logic
│   └── images/             # Process, portrait, and production photography
└── README.md
```

## Running Locally
You can open `index.html` directly in any modern browser, or run a local static server:
```bash
# Python
python -m http.server 8088

# Node
npx serve .
```
